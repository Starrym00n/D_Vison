# 视觉方案

# 一、核心简介

![Image](https://internal-api-drive-stream.feishu.cn/space/api/box/stream/download/authcode/?code=MzgzMWExNjhiM2UxNDcxODNlMjBlNjVlYTk0N2NhMTRfNTZlZDQwYjgxYWY0OTFlYzE4ZmEyZWQzYjI3ZDliNzVfSUQ6NzY4NjQ5OTY1NTM0NTQyNTU5OV8xNzg5NzM2MDI1OjE3ODk4MjI0MjVfVjM)

视像头视野图示

1. 巡线：通过摄像头固定高度位置，让小车在到达指定停车位置前按照图示中水平黑线进行巡线（使用`maix.image.Image`中`get_regression`）传回两个参数

- `theta`：轨迹线相对画面的角度，可以用来判断车头应该向左还是向右修正。

- `rho`：轨迹线到画面左上角的距离，可以用来判断轨迹线是否偏离画面中心。

控制端可使用这两个参数使用**PID**完成巡线

详情见参考链接https://wiki\.sipeed\.com/maixpy/doc/zh/projects/line\_tracking\_robot\.html

2. 特征识别：通过对“⊥”型特征的检测计数，在检测到第三个“⊥”型特征后向控制端传递信号，由控制端操作小车到指定停车位置并进行出入库操作，并对计数清0

3. 在完成倒车出入库操作后，再同理继续进行巡线与特征检测操作，完成侧方停车。

4. 全程数据传输使用UART协议，必须占用TXD、RXD，如有必要可保留一个GPIO

# 二、工具链

1. 硬件：MaixCAM2，搭载OS04D10摄像头

2. 软件：MaixPy，UART，OpenCV
